Designing a 16-Channel Analogue Data-Acquisition Front End

Practical integration guide for a multiplexed SAR ADC such as the Texas Instruments ADS7953-Q1, interfaced to an STM32 over SPI. Covers architecture, analogue conditioning, power/reference, grounding, firmware sequencing, PCB layout, validation and qualification.

1. Purpose and design assumptions

The objective is to measure up to 16 analogue signals using one ADC IC. The ADC contains an internal 16:1 multiplexer, a sample-and-hold network, a SAR conversion engine and a serial digital interface. The STM32 selects channels or configures a scan sequence, clocks data over SPI, and stores calibrated measurements.

Important component verification: Treat this document as an architecture and design guide, not a released schematic. Before layout or procurement, verify the exact ADS7953-Q1 orderable variant, pin names, supply limits, input ranges, reference configuration, SPI timing, command format and automotive qualification status against the latest TI datasheet and product page. Do not copy pin voltages or register bit fields from a generic ADC example.
ADC familyExample device

ADS7953-Q1, 16-channel, 12-bit multiplexed SAR ADC with serial interface.

Controller

STM32 with an SPI peripheral and one GPIO for chip-select.

Sampling mode

Sequential channel sampling; not simultaneous sampling of all 16 channels.

Input type

Assume voltage-output sensors initially. Current-loop, bridge, thermocouple and RTD sensors need dedicated front ends.

Functional blocks

  1. Sensor interface: provides the voltage or conditioned signal representing the physical quantity.
  2. Protection: limits damage from ESD, wiring faults, overvoltage and transients.
  3. Signal conditioning: scales, offsets, buffers and filters the signal to fit the ADC input range.
  4. ADC: selects one channel, samples its voltage, converts it to a digital code and shifts the result out.
  5. STM32: configures the ADC, controls chip-select and SCLK, receives data and converts codes into engineering units.
Key system decision: A multiplexed ADC samples channels one after another. If the application needs phase-aligned samples across channels-for example, control-loop measurements of rapidly changing motor phase signals-consider simultaneous-sampling ADCs or multiple synchronised ADCs instead.

3. How the multiplexed ADC works

CH0 CH1 CH2 … CH15
down
Internal 16:1 analogue multiplexer
down
Sample-and-hold / acquisition capacitor
down
12-bit SAR conversion engine
down
Serial output register -> SPI -> STM32

The multiplexer connects one selected input to the ADC's internal sampling network. During the acquisition interval, the sampling capacitor charges toward the input voltage. The ADC then holds that voltage and performs a successive-approximation conversion. The result is a digital code that is shifted to the MCU through the serial interface.

Some ADCs pipeline conversion results: a frame may transmit a command for the next channel while returning the result from the previously selected channel. Firmware must follow the ADS7953-Q1 timing diagram and tag each received word with the correct channel. Discard or ignore invalid startup data as described by the datasheet.

4. Analogue input design

Do not connect every sensor directly to the ADC without checking its output range, source impedance, bandwidth, fault behaviour and grounding. Design each channel against the worst-case electrical conditions-not just the nominal sensor voltage.

4.2 Input range and scaling

  • Establish the ADC's configured input range and absolute maximum ratings from the datasheet.
  • Keep normal sensor output, tolerance, supply variation, startup overshoot and fault recovery within the permitted input range.
  • If a sensor outputs 0-10 V but the ADC accepts at most 0-5 V, use a precision divider or amplifier stage. Include resistor tolerance, temperature coefficient, input leakage and protection leakage in the error budget.
  • For bipolar signals, use an appropriate bipolar-capable ADC/front end or level-shift the signal into the ADC's allowed unipolar range. Never apply a negative voltage unless explicitly allowed.
  • Do not assume the ADC input range is the same as its analogue supply voltage or reference voltage.

4.3 RC filter design

A simple first-order low-pass filter uses a series resistance and a capacitor to analogue ground. Its approximate cutoff frequency is:

fc = 1 / (2 × π × R × C)

Example only: R = 1 kΩ and C = 100 nF gives fc ≈ 1.59 kHz. This may attenuate high-frequency noise, but it is not automatically a good value for every ADC input. The source impedance plus filter resistance must allow the ADC sampling capacitor to settle during the acquisition time.

Multiplexer settling: When the MUX switches from a low voltage to a high voltage channel, the input network must settle before conversion. A large series resistor or capacitor can cause channel-to-channel memory/crosstalk or conversion error. Check the ADC's acquisition time, input capacitance, leakage, recommended drive circuit and settling requirements. A buffer may be necessary.

4.4 When to use an op-amp buffer

  • Sensor output impedance is high.
  • Sensor cannot drive the ADC's switched-capacitor input.
  • Long cable capacitance or a heavy filter creates slow settling.
  • Gain, attenuation, differential-to-single-ended conversion or level shifting is required.

Select an amplifier for input common-mode range, output swing, offset, bias current, noise, bandwidth, slew rate, stability with capacitive loads, supply voltage and temperature grade. Confirm it can settle to the required accuracy within the available acquisition interval.

5A. Passive components directly around the ADS7953-Q1

This section adds the device-specific passive network called out in TI's ADS79xx-Q1 datasheet. The supply and reference capacitors below are explicitly specified by TI, while the per-channel capacitors are part of TI's recommended input-settling application circuit.

Core ADS7953-Q1 passive population: two 1-uF capacitors for the two +VA pins, one 1-uF capacitor for +VBD, one 10-uF capacitor from REFP to REFM, and one 150-pF capacitor from each of the 16 channel inputs to the analogue ground return as shown in TI's typical unbuffered-MXO circuit. Add optional series resistors / protection only after checking the sensor source and fault environment.

5A.3 Why TI shows 150 pF on every channel

The ADS79xx-Q1 has an internal input capacitance of approximately 15 pF. When the multiplexer switches channels, charge associated with the previous channel can disturb the newly selected input. TI explains that a 150-pF capacitor at each channel input reduces the initial disturbance, after which the sensor/source must settle the remaining error within the acquisition time.

For the unbuffered-MXO example, TI gives source-impedance limits for 12-bit settling at 1 MSPS of approximately 100 Ω in the 1×REF range and 250 Ω in the 2×REF range. These are conditions from the datasheet's example, not blanket limits for every scan rate or circuit. The allowable source impedance changes with sampling rate and input range.

Important: a 150-pF channel capacitor is not a substitute for a properly calculated anti-alias filter, and it does not mean you can use a high-value series resistor without checking settling. If the sensor has high output impedance, use an appropriate buffer or reduce the scan rate / acquisition demands as supported by the datasheet. Test worst-case channel transitions (near 0 V to near full-scale and back).

5A.5 Layout rules for these passives

  • Place CVA1, CVA2 and CVBD directly beside their respective supply pins. Keep capacitor-to-pin and capacitor-to-ground paths short and wide.
  • Place CREF directly beside REFP and REFM. Connect its ground terminal to REFM with a very short route; do not put a via between the capacitor and the ADC pin.
  • Place each 150-pF channel capacitor close to the corresponding input pin / channel trace, with a short low-inductance return to the analogue ground region.
  • Keep analogue input traces and filter components on the analogue side of the ADC. Keep SCLK, SDI, SDO and MCU routing on the digital side.
  • TI's layout guidance shows an analogue-ground copper fill under the IC tying AGND, BDGND, AINM and REFM, with multiple vias to the analogue ground plane. Follow the datasheet's exact ground layout example rather than splitting the plane arbitrarily.
  • Do not place vias between the local decoupling capacitor and the corresponding device pin where TI advises against them.

5. Power supply and voltage reference

Power pins, reference pins and allowable voltages must be taken from the exact device datasheet. Avoid treating generic example voltages as guaranteed pin connections.

A precision reference is a separate block with its own load, decoupling and routing requirements.

  • Confirm all ADC supply rails, sequencing requirements and recommended operating ranges.
  • Use local ceramic bypass capacitors at each supply pin, placed close to the pins with short return paths. Add bulk capacitance where required by the datasheet and regulator stability needs.
  • Keep high-current digital return paths from flowing through sensitive analogue input/reference areas.
  • Use a low-noise regulator or filtered rail where the ADC performance requires it. Check PSRR over the actual switching-regulator noise spectrum.

5.2 Reference selection

The reference voltage sets the conversion scale. Reference initial accuracy, temperature drift, noise, long-term stability, load regulation, output drive and startup behaviour all affect measurement accuracy.

  • Select a reference whose output and drive capability meet the ADC reference input specification.
  • Follow the datasheet's reference bypass capacitor value, dielectric and placement guidance.
  • Do not add a large capacitor or buffer blindly; reference inputs may have dynamic loading and stability constraints.
  • Route the reference as a quiet analogue net, away from SCLK and switching nodes.
  • Consider measuring a precision calibration source or monitoring the reference in production/test if system accuracy requires it.
Correction to avoid a common mistake: Do not assume “5 V analogue supply + 3.3 V digital supply + 2.5 V reference” is the correct wiring for every ADS7953-Q1 variant. Verify the exact pin names, rail ranges and reference mode in the current datasheet before making a schematic.

6.1 SPI configuration

Set SPI clock polarity (CPOL), phase (CPHA), maximum clock frequency, bit order and frame length exactly as specified in the ADC datasheet. Do not guess SPI mode 0 or mode 1. Confirm the timing diagram for the selected part and operating mode.

  • Use a GPIO-controlled CS if it gives clearer control over frame timing.
  • Keep CS low for the exact frame length required by the ADC; observe setup/hold and minimum high-time requirements.
  • Check logic-level compatibility. The ADC digital I/O rail determines its input thresholds and output levels.
  • Use modest SCLK initially during bring-up; increase only after confirming timing margin and signal integrity.
  • Use a logic analyser or oscilloscope to verify CS, SCLK, MOSI and MISO.

6.2 Frame timing and pipelining

Some multiplexed ADCs return the conversion result for the channel selected in the previous frame while accepting a new channel command in the current frame. This is called pipelining. Firmware must maintain a “requested channel” versus “result channel” association. Read the ADS7953-Q1 datasheet's exact frame diagrams, command format and startup behaviour.

7. Firmware structure for STM32

7.1 Recommended software layers

  1. Low-level SPI driver: transfers a frame and handles timeout/error conditions.
  2. ADC driver: builds device-specific command words, decodes response words and manages the channel pipeline.
  3. Acquisition manager: scans configured channels and timestamps sample sets.
  4. Signal processing: converts raw codes to volts and engineering units, applies calibration and filtering.
  5. Application layer: uses measurements for monitoring, logging or control.

7.2 Illustrative pseudocode

#define ADC_CHANNELS 16 uint16_t adc_raw[ADC_CHANNELS]; float adc_voltage[ADC_CHANNELS]; void acquire_all_channels(void) { /* * Device-specific: * 1. Build the ADS7953-Q1 command for a channel. * 2. Assert CS and transfer the required frame. * 3. Decode the response belonging to the previous selection * if the device's pipeline requires this. * 4. Associate each result with the correct channel. * * This is pseudocode, not a drop-in ADS7953 register driver. */ for (uint8_t ch = 0; ch < ADC_CHANNELS; ch++) { uint16_t tx_word = build_adc_command(ch); uint16_t rx_word = spi_transfer_16bit(tx_word); process_response_using_datasheet_pipeline(rx_word); } /* Flush/complete the final pending conversion as required by the device's documented sequencing. */ }

7.3 Data conversion

/* Illustrative only: confirm the ADC's exact coding and range. */ float code_to_voltage(uint16_t code, float full_scale_voltage) { return ((float)(code & 0x0FFF) / 4095.0f) * full_scale_voltage; }

7.4 DMA and timing

  • For low channel rates, blocking SPI transfers may be sufficient and easier to debug.
  • For frequent scans, use SPI DMA to reduce CPU load. Keep TX and RX buffers correctly aligned and sized for the frame format.
  • Use a timer to schedule scan cycles rather than relying on software delays.
  • Use a timestamp per scan set if data will be compared over time.
  • Check for SPI overrun, timeout, DMA errors and missed acquisition deadlines.
  • Do not assume that a single 16-frame scan samples all channels at the same instant.

8. ADC resolution and measurement calculations

For an ideal 12-bit ADC with a unipolar 0-5 V input range, the number of output codes is 212 = 4096. The ideal code width is approximately:

LSB = Full-scale range / 4096 = 5 V / 4096 ≈ 1.2207 mV

Using an ideal straight-binary transfer approximation, a 1.25 V input corresponds to:

Code ≈ (1.25 / 5.0) × 4095 ≈ 1024

The exact transfer function, endpoint convention, coding and full-scale definition must be confirmed in the ADC datasheet. Resolution is not the same as accuracy: reference error, offset, gain error, INL, noise, resistor tolerance and sensor error all contribute.

9. PCB layout, grounding and EMC

9.1 Placement strategy

  • Place the ADC close to the analogue input connector or front-end circuitry to minimise high-impedance trace length.
  • Place local decoupling capacitors immediately adjacent to their supply pins.
  • Place the reference close to the ADC reference pins and follow the reference manufacturer's layout guidance.
  • Keep the MCU and fast digital buses far enough from sensitive analogue nodes to reduce coupling.
  • Keep switching regulator inductors, switch nodes, gate-drive loops and high-current paths away from the ADC inputs and reference.

9.2 Grounding

Prefer a continuous, low-impedance ground reference plane with controlled return-current paths. Partition placement and routing by function rather than automatically splitting the ground plane. If separate analogue and digital ground pins exist, connect them as the ADC manufacturer recommends. Avoid routing digital return currents through the analogue input area.

9.3 SPI signal integrity

  • Route SCLK with a clean return path and avoid unnecessary stubs.
  • Keep SPI traces away from high-impedance analogue input traces.
  • Consider small source-series resistors on fast digital outputs only if signal-integrity analysis or measurement indicates ringing; do not add values blindly.
  • Check overshoot, undershoot, rise time and setup/hold at the ADC pins.

9.4 Connectors and cables

External sensor wiring can carry ESD, EFT, surge, ground-offset and conducted RF disturbances. Place protection close to the connector, provide a deliberate chassis/ground return strategy, and verify that protection-device capacitance and leakage do not degrade the analogue measurement.

10. Protection and fault handling

Protection must be designed from the actual electrical environment and applicable system requirements. A series resistor alone does not make an input robust.

  • Define normal operating range, maximum continuous voltage, transient waveform, reverse polarity and open/short sensor faults.
  • Choose TVS, clamps, series impedance and current limiting so the ADC pin never exceeds absolute maximum ratings during specified faults.
  • Check clamp leakage over temperature; leakage can create measurement errors on high-impedance sensor inputs.
  • Check protection capacitance against signal bandwidth and ADC settling.
  • Consider input disconnect or current-limiting circuitry for faults that could damage the shared ADC or other channels.
  • Implement plausibility checks, range checks, stuck-at detection, open-wire detection where feasible, and timeout/error flags.
Safety: Do not connect unknown external signals directly to a development board or ADC. Measure and characterise the source first. Ensure all input voltages, including transient and power-off conditions, remain within the device's absolute maximum limits.

11. Hardware bring-up and validation plan

  1. Power-only test: verify every rail, sequencing, ripple and current consumption before connecting sensors.
  2. Reference test: measure reference voltage at the ADC pin using a suitable meter; check startup and stability.
  3. Digital test: read documented device registers/status where supported; verify SPI mode, frame length and timing with a logic analyser.
  4. Known-voltage test: apply a precision voltage to one channel and compare raw code against the expected transfer function.
  5. All-channel test: apply different stable voltages to each channel and confirm channel mapping.
  6. Settling test: alternate channels between near-zero and near-full-scale inputs; check for memory effects and crosstalk.
  7. Noise test: short or terminate inputs as recommended and record noise distribution.
  8. Temperature test: measure offset/gain drift over the intended operating temperature range.
  9. Fault test: test open circuit, short circuit and defined transient cases using a controlled test setup.
  10. System test: test with actual sensors, cable lengths, power converters and radio/compute activity enabled.

12. Automotive and defence qualification considerations

AEC-Q100 is an automotive IC qualification framework. MIL-STD-883 is a military microcircuit test method standard. These are not interchangeable labels, and neither one by itself qualifies the complete circuit board or end equipment.

  • For automotive selection, verify the exact orderable part number, AEC-Q100 grade, temperature range, qualification report and product change notification process.
  • For defence/aerospace use, establish the required screening level, traceability, lot acceptance, temperature range, radiation requirements if applicable, and approved parts process with the customer/programme.
  • An “EP” or enhanced-product offering should not be represented as MIL-STD-883 qualified unless the manufacturer documentation explicitly supports the required qualification and screening.
  • Check lifecycle status, country of origin requirements, counterfeit avoidance, approved distributor traceability and long-term availability.
  • System qualification may include environmental, vibration, shock, humidity, temperature cycling, EMC/EMI, power transients and functional safety/reliability tests depending on the programme.
Procurement rule: Ask the manufacturer or authorised distributor for written confirmation against the exact part number and revision. Do not rely on a marketplace listing or a generic family-level statement.
